## Install it first — it is not published in TradingView

This repository file does **not** install itself into TradingView. The GitHub default branch (`master`) also does not contain it yet; the file is on branch `arena/1ccc44fe-ict-knowledge-library`.

1. Open `tools/snm-plus.pine` in the workspace viewer, or on GitHub select that branch and open `tools/snm-plus.pine` (not the archived `.txt`). Copy the **entire file**, beginning with `//@version=6`.
2. In TradingView open a chart → **Pine Editor** (bottom tab) → **New / Blank indicator**. Select all the placeholder code, paste 3.59, click **Save** (name it `SNM+ 3.59`), then **Add to chart**.
3. Remove the older SNM+ instance from the chart to avoid overlapping drawings. The chart legend should say **SNM+ 3.59**. Only then open its **gear → Inputs** for the new settings below. If the legend says `SNM+ 3.58` or earlier, you are still looking at an older build.
4. If TradingView reports a compiler or resource error, send the exact message and line number before trusting any chart output. This repo's checker is not TradingView's server compiler.

## What the core still does

SNM+ **draws setups, not trades**. It tracks named and intraday swing sweeps, uses an iFVG inversion or the optional Sweep + CISD close as trigger, and classifies C / RB / RV from 15m structure. A++/A+/A/B, the D/T/E checklist, HTF FVG delivery, HRL avoidance, BE/TP1/TP2, NY-time windows, news dimming and ARMED/FORMING previews remain the original design. A++ still requires premarket + macro reversal context. `Auto outcome (backtest)` remains **off by default**; when switched on, its mechanical tally counts at most two qualifying setups/two losses per day. This is a study tool, not an order-placement strategy. An active preview can change before the candle closes; wait for the confirmed tag.

## Replay the missed short, without changing entry rules

1. Paste 3.56 and switch **Diagnostics (study only) → Show iFVG near-miss reasons = On** once; leave sweep/grade/gap controls unchanged. On MNQ1! 1m replay the *same* broker feed and trading date around **04:30–04:42 New York**. The later blue B CISD long is a different event. The screenshot creation date does not establish the replay trading date.
2. Read the amber **S** (short) or **L** (long) label directly: it contains the first 18 characters of the reason after the side. The bottom-left **iFVG why-not** row shows the *most recently logged* full code string, with its NY date/time. Stop replay on or immediately after the bar of interest; advancing farther replaces the row with a later reason. A label is a rejected candidate / rendered B, **not a trade**. A `SHORTS ONLY` banner at a later bar does not establish earlier state. If the bottom-left checklist panel overlaps this row, choose a different checklist position in Display during study.
3. Code key: `NO SWEEP` = no active recognised sweep; `SWEEP LATE` = inversion past the allowed sweep age; `GAP TOO OLD` = gap formation too far before sweep; `TF RANK USED` = same/higher gap rank already inverted on that sweep. A grade label begins with gap TF and grade, then failing checks: `STOP` (stop invalid), `SWEEP` (no key/internal sweep), `NO-HTF` (delivery absent), `DISP` (displacement absent), `NO-TP` (target/draw absent), `V-SHAPE`, `BIAS`, `NY-BLOCK`, `TTFM`, `SMT`, `DUP`, `WINDOW`, `BELOW-[grade]` (display floor), `B-ONLY`. Multiple codes can appear. It is a snapshot of known checks, not proof the annotated short should have qualified.
4. If no label appears, SNM+ did not observe a close-through of a *registered* three-candle gap there (or the gap was below the minimum size, outside history, or aged out of the registry). This does **not** prove the annotated iFVG was invalid; capture formation candles and the close-through bar with exact chart time/broker feed before changing detection. A wick through the edge is not a confirmed inversion. Switch Diagnostics back Off after study. No TF-specific diagnostic setting is required; keep the existing Fixed/Auto gap pairing.

## Pair and timeframe

See `tools/snm-settings-by-pair.md` for the maintained profile. `SMT sibling = Auto`, `Fractal pairing (HTF candle) = Auto`, and the optional `HTF CISD timeframes = Auto` require **no manual changes when switching between 1m, 3m, 5m and 15m** on index futures. `Structure timeframe (C / R) = 15m` and `HTF gap timeframe mode = Fixed` preserve the 3.47 default gap slots; switch the latter to Auto **once** if you want slots to follow chart timeframe automatically, then compare delivery and tags on replay. ## What we did *not* import from CISD Model+

Its alternate *entry* CISD flip engine, HTF/CTF label merging, real-time SMT and current-timeframe-FVG-without-sweep are **not in this build**. The opt-in HTF CISD layer is context-only, not an additional setup engine. The optional stop-based Dim/Hide display mode is implemented without adopting the donor’s close-only invalidation rule. They would change what qualifies as a setup, draw unconfirmed information, or consume additional object budget. They remain described as opt-in follow-up work in `tools/snm-integration-plan.md`, not falsely advertised as shipped. We also did not import its A+/A/B-/C grading, which conflicts with SNM+'s DTE rulebook.
