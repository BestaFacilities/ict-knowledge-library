# SNM+ 3.70: pair / timeframe / session settings

Update this file in the **same commit** as any new input, changed default, or renamed group in `tools/snm-plus.pine`. All times below are New York time (DST handled by Pine's `America/New_York`). This is setup display guidance, not investment advice or a performance claim.

| Symbol on chart | SMT sibling (`Auto`) | Default point-based fallbacks | Notes |
|---|---|---|---|
| NQ | ES | EQ tolerance 3 pt; max stop 75 pt; edging 50 pt | Keep Auto pair. |
| MNQ | MES | Same NQ fallbacks | Keep Auto pair; the SNM+ risk sizing uses `syminfo.pointvalue`, not the symbol name. |
| ES | NQ | EQ tolerance 0.75 pt; max stop 18 pt; edging 12 pt | Keep Auto pair. |
| MES | MNQ | Same ES fallbacks | Keep Auto pair. |
| XAUUSD / other | none | EQ fallback 4 ticks; edging fallback 50 ticks; no auto max-stop point threshold | Do not assume ES is the correlated feed. Manual SMT symbol only after confirming data and directionality on your broker's chart. |

These are the script's **existing auto defaults**, not new parameter recommendations. Manual values of 0 in those inputs mean Auto, except `iGapMin` which is a multiple of ATR. Do not copy MNQ point distances into gold.

**3.68 simplification (all pairs/timeframes):** the TTrades Fractal Model and the Clean/MX Lite chart views are removed. Only the Current view remains (with ARMED/FORMING previews and the Now row). The checklist has 7 rows and the confluence score is out of 3. No pair/timeframe retuning; the core setup logic is unchanged.

**3.70 SMT sweep labels (all pairs/timeframes):** `Confluence → Show SMT labels at sweeps` defaults **On**. At each sweep, **SMT ✓** means the pair did not take its level (divergence); **SMT ✗** means it did. One per side per bar, capped at 30. Display-only; requires `SMT with ES / NQ` On and a valid pair feed. No pair/timeframe retuning.

**3.69 extras removal (all pairs/timeframes):** diagnostics, HTF CISD context, NWOG, Monday range, Judas, and 5M HTF gap zones are removed (2137 lines, 112 inputs). The Judas highest-TF waiver is gone: the highest-TF iFVG is now required unless the setup is Sweep + CISD. The 5M iFVG *trigger* gaps remain; only the 5M HTF delivery/draw zones are gone. No pair/timeframe retuning; setup qualification, grades, targets, tracker and alerts are otherwise unchanged.

**3.67 SMT divergence markers (all pairs/timeframes):** `Confluence → Show SMT divergence markers` defaults **Off**. When On with `SMT with ES / NQ` On and a valid Auto/Manual pair feed, **SMT-** marks a swing high where the chart prints a higher high but the pair prints a lower high, and **SMT+** marks a swing low where the chart prints a lower low but the pair prints a higher low. Markers use the main 5/5 pivots and appear in the Current view. Display-only: no effect on setups, grades, targets, tracker, or alerts. No pair/timeframe retuning; the markers need the same SMT pair feed as the SMT check.

**3.66 compile fixes (all pairs/timeframes):** 3.65 did not compile in TradingView (CE10272/CE10271). 3.66 fixes the Simple-panel `rv`/`ro` declaration order and the CW10026 inline-input warnings: only the first input of each inline group now carries a title (18 titles removed), so the Settings/Inputs tab aligns. No input, default or behaviour changes; the 3.65 build should not be used.

**3.65 checklist clarity (all pairs/timeframes):** the checklist panel now separates **LAST SETUP** (muted header under the `SNM+ LONG/SHORT · grade` header; D/T/E rows in Simple, the eight check rows in Full) from **NOW** (the state row, when `Show setup state row (study)` is On). States read **✔** pass, **✖** fail, **n/a** when the check is disabled (`TTFM → Off` for the TTFM closure row; SMT off for SMT/PSP), and **–** when there is no data yet. A disabled check never reads as a failure. No new input and no pair/timeframe retuning: the existing `Detail level` (Simple/Full) and `Show setup state row (study)` controls govern the panel, and D/T/E meanings, grades, the one-bar `PREV CLOSE` behaviour and confirmed-bar priority are unchanged. In Replay, the LAST SETUP block must not move when NOW changes.

**3.64 MX Lite display controls (all pairs/timeframes):** `Display → Chart view = Current (3.54)` remains the default. `MX Lite` is an optional compact presentation; `Show setup labels` and `Show setup zones / iFVGs` default On and independently hide drawings only. `Latest setup only (MX Lite)` defaults On but is active only in MX Lite; Off keeps all retained setup drawings. No pair-specific points, SMT mapping, timeframe selection or alert setting changes when switching views or chart TF. `Show setups from grade` is still the existing setup gate—do not use it as a visibility substitute. Hidden historical drawings remain allocated until the normal setup-history cap prunes them; this is not an object-budget reduction. Outcome calculations continue, but hidden setup tags do not reveal tracker result text/tooltips.

| Entry chart TF | Chart iFVG + optional higher inversions | HTF delivery: Fixed (default) → Auto (opt-in) |
|---|---|---|
| 1m | 1m, 2m, 3m, 5m | **15m / 1H / 4H** → same |
| 3m | 3m, 5m | same → same |
| 5m | 5m | **15m / 1H / 4H** → **1H / 4H / 1D** |
| 15m | 15m | same Fixed slots (15m duplicates the chart TF) → **1H / 4H / 1D** |
| 30m–1H | chart TF | Fixed stays 15m/1H/4H → Auto selects **4H / 1D / 1W** (only slots above chart TF are admitted) |

`HTF gap timeframe mode = Fixed` reproduces the 3.48 calculation and delivery. In Fixed, `Fixed gap TF 1 / 2 / 3` default to 15/60/240; choose distinct TFs above the chart if overriding. Auto is a deliberate new **signal-context** choice, not just display: FVG delivery and target availability can change. No settings edits are needed *between* chart timeframes once Auto is chosen; choose it once and compare with Fixed in replay.

**Session / PD level priority (any pair/TF; combined NY in 3.63):** in `Liquidity levels`, `Always show sessions + PDH/PDL` defaults On. With the global `Draw the nearest levels` switch On, every enabled, untaken completed-session Asia/London/Premarket/NY high/low and PDH/PDL remains visible regardless of `other / side`; NY is one 09:30–16:00 range, not separate AM/PM pools. The existing individual session and `Previous day H/L` inputs remain opt-outs. The default `other / side = 2` adds two nearest secondary levels on each side; set it to 0 for only the core levels. `Keep swept levels to their sweep` also defaults On: after the confirmed sweep bar, its muted dashed segment ends there instead of disappearing or extending forward. The 20-record history cap controls display only; session/PDH/PDL hits are retained ahead of secondary swings, and older core history rolls off only when the cap is full of core hits. Consumed levels remain removed from active sweep/target logic. No pair- or timeframe-specific setting is required. In Replay, pause on the confirmed sweep bar and verify the line's endpoint is that bar; the next bar must not extend the historical segment.

**3.63 combined NY liquidity and date labels (any pair/TF):** `Liquidity levels → New York (NY)` defaults On with one NY session of `09:30–16:00`, replacing the separate NY AM and NY PM pools from 3.62. The completed high/low enters the existing active sweep, target and setup evaluation after the session closes; it remains functional liquidity, not a decorative range. Asia, London and NY level labels default to `DD/MM ASIA.H/L`, `DD/MM LON.H/L` and `DD/MM NY.H/L`; the prefix date is the New York calendar date of the bar that formed each extreme. `Date-stamp Asia/London/NY labels` defaults On and can be turned Off to restore the undated label style. Premarket retains `PRE.H/L`. The separate `Setup → NY AM rulebook window` defaults to `09:30–11:00`, and trading/alert windows are unchanged. Disable the single NY switch or edit its hours if needed; no chart-timeframe retuning is required.

**Diagnostics for a missed MNQ 1m short (3.55, removed in 3.69):** on the same broker feed and *trading* date, enable `Show iFVG near-miss reasons` once and pause replay around the marked inversion. Amber S/L labels now print short codes without hover; the bottom-left `iFVG why-not` row prints the latest complete reason with NY date/time. Advance one bar at a time because the latest row changes when another candidate appears; see `snm-plus-guide.md` for the code key. This still sees only registered, confirmed close-throughs—not wick-only reactions, raw gaps below the size filter, or gaps evicted from the registry. It never grants a trade, removes the key-sweep rule, or overrides manual bias. Keep your existing Fixed/Auto gap pairing on TF switches; diagnostic mode needs no TF tuning. Turn it Off after study.

**3.55 view for any pair/TF (Clean removed in 3.68):** `Display → Chart view = Current (3.54)` preserves the existing auxiliary drawing density (the text/count corrections still apply). `Clean` keeps every enabled session/PDH/PDL level (including the combined NY range in 3.63) when priority is On, plus one nearest additional level per side, one gap per side and at most one price-containing HTF gap (when that option is On); swept-level history also remains visible if enabled. It retains the enabled preview/confirmed plans, status and compact D/T/E, while hiding auxiliary drawings. It does **not** alter the Fixed/Auto gap ladder, SMT sibling, TTFM filter, alerts or sizing and requires no adjustment when switching 1m/3m/5m/15m. On NQ, MNQ, ES, MES and XAUUSD, sizing uses `syminfo.pointvalue`; a displayed **SIZE 0** means no unit was calculated: check the risk budget and chart feed's point value—do not treat the drawn tag as a tradable order. Off-feed SMT remains unverified, not a positive signal.

**3.57 visual adaptation for every pair/TF (TTrades removed in 3.68):** TTrades → `HTF candle spacing = Auto (compact)` and Display → `Checklist panel position = Auto` are the **new display defaults**. HTF candle *drawings* start +24 chart bars on 1m, +18 on 2m–5m, +12 above 5m; their body/gap are 5/3 bars through 5m and 3/2 above 5m. On 1m–5m the checklist is middle right; above 5m it stays bottom right. No symbol-specific point conversion or manual adjustment on TF switches. Use `Manual (3.56)` for the 3.56 candle positions (start 50, width 5, gap 3, unless you customized them), and `Bottom Right` for the old panel position. Clean and MX Lite hide the HTF candle strip but retain the existing checklist. This does not alter HTF pairing, gap delivery, entry eligibility, stops, grade, size or alert content. Pine cannot control TradingView's horizontal zoom, right margin or the browser window width.

**3.58 state row (all pairs/TFs):** `Display → Show setup state row (study)` defaults **Off**. Enable once if you want a read-only **Now** row on the existing checklist across 1m/3m/5m/15m and NQ/MNQ/ES/MES/XAUUSD: the active sweep/existing preview (when enabled) or the latest evaluated iFVG/CISD candidate on this confirmed bar, its known first block, and alert *eligibility*. In 3.60 an evaluation remains visible as muted `PREV CLOSE` for the next chart bar only, unless a fresh confirmed evaluation takes priority; it is not a live signal. No new symbol pair, fixed point thresholds, alert path or manual TF setting. With the row Off, 3.57 panel contents return; the 3.57 visual Auto settings remain the separate defaults. If a row becomes too wide for a narrow chart, turn it Off or move the panel to a fixed corner. No one-row display is a guarantee of an unseen gap, missed sweep, or delivered TradingView alert.

**HTF gap lifecycle (3.51 default change):** `HTF FVG invalidation = Hybrid (HTF close)` follows each strictly higher slot TF automatically: 1H gaps await a confirmed 1H close, 15m gaps a 15m close, and so on. A chart-TF close beyond the far edge immediately marks the zone **BREACHED** (grey dashed, no delivery/target/sponsorship/edging/map credit), rather than deleting it; a confirmed source-TF close beyond deletes it, or a confirmed reclaim reactivates it for *future* setups. A manual Fixed slot at/below the chart TF still invalidates on chart close. `Also the gaps price is trading inside` defaults **On** (display only), making near-price gaps visible without manual TF-specific retuning. To restore **3.50**, set `HTF FVG invalidation = Chart close (3.50)` and `Also the gaps price is trading inside = Off`. Prefer matching broker/symbol/replay time when comparing, because a box is not proof of delivery.

**HTF CISD context (new 3.50, removed in 3.69):** set `Enable confirmed HTF CISD context = On` once; `HTF CISD timeframes = Auto` then picks 2m/3m on 1m, 5m/15m on 3m, 15m/30m on 5m, 1H/4H on 15m, 4H/1D on 1H. The chart and lower TFs are skipped. The 60-minute freshness window starts at the confirmed HTF candle's actual close (also across market gaps); it is wall-clock minutes, **not 60 chart bars**. `Draw confirmed HTF CISD lines` can be switched off independently without disabling the tooltip read. The 4-line cap is global. No change to entry eligibility, grade or alerts; on XAUUSD this is the same chart symbol's HTF candle-leg context, unrelated to the SMT sibling. If you choose Manual, use two distinct TFs above your entry chart.

**3.56 B-alert choice for every symbol/TF:** `Alerts → Alert rulebook-blocked B (study) = Off` by default. At `Show setups from grade = B` with `Rulebook blocks set the grade to B = On`, a reversal or Sweep + CISD outside NY AM still draws B/✖ but does not send a *confirmed* alert. Turn the study override On only if you need a clearly marked `STUDY BLOCKED` confirmed alert. If the B floor is not selected, the blocked tag remains hidden as before. All other B confirmations continue under the previous alert master, category, window and news rules. No per-timeframe tuning or change to entry, grade, sizing or SMT is implied. Forward alerts, not replay labels, are needed to verify delivery; recreate the TradingView alert after changing its input snapshot.

**Session defaults:** Asia 20:00–00:00; London 02:00–05:00; Premarket 08:00–09:30; one combined NY liquidity range 09:30–16:00. The separate NY AM rulebook window remains 09:30–11:00; it gates the existing reversal/Sweep + CISD rules but is not another pool. Trading windows remain Asia/London/NY AM, and the combined NY range does not add afternoon setup or alert time. Session labels for Asia, London and NY use `DD/MM SESSION.H/L`, with the date taken from the NY calendar date of the bar that formed each extreme; Premarket remains `PRE.H/L`. Macro windows: 09:50–10:10 and 10:50–11:10. Automatic NFP blackout approximates first Friday 08:30 NY (check actual release date); type other red-folder dates in `Other releases` each week. The optional alert windows narrow, never widen, the original trading/news window gate.
