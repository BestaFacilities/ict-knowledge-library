# SNM+ 3.57: pair / timeframe / session settings

Update this file in the **same commit** as any new input, changed default, or renamed group in `tools/snm-plus.pine`. All times below are New York time (DST handled by Pine's `America/New_York`). This is setup display guidance, not investment advice or a performance claim.

|---|---|---|---|
| NQ | ES | EQ tolerance 3 pt; max stop 75 pt; Judas candle 25 pt; edging 50 pt | Keep Auto pair. |
| MNQ | MES | Same NQ fallbacks | Keep Auto pair; the SNM+ risk sizing uses `syminfo.pointvalue`, not the symbol name. |
| ES | NQ | EQ tolerance 0.75 pt; max stop 18 pt; Judas candle 6 pt; edging 12 pt | Keep Auto pair. |
| MES | MNQ | Same ES fallbacks | Keep Auto pair. |

These are the script's **existing auto defaults**, not new parameter recommendations. Manual values of 0 in those inputs mean Auto, except `iGapMin` which is a multiple of ATR. Do not copy MNQ point distances into gold.

`HTF gap timeframe mode = Fixed` reproduces the 3.48 calculation and delivery. In Fixed, `Fixed gap TF 1 / 2 / 3` default to 15/60/240; choose distinct TFs above the chart if overriding. Auto is a deliberate new **signal-context** choice, not just display: FVG delivery and target availability can change. No settings edits are needed *between* chart timeframes once Auto is chosen; choose it once and compare with Fixed in replay.

**Diagnostics for a missed MNQ 1m short (3.55, off by default):** on the same broker feed and *trading* date, enable `Show iFVG near-miss reasons` once and pause replay around the marked inversion. Amber S/L labels now print short codes without hover; the bottom-left `iFVG why-not` row prints the latest complete reason with NY date/time. Advance one bar at a time because the latest row changes when another candidate appears; see `snm-plus-guide.md` for the code key. This still sees only registered, confirmed close-throughs—not wick-only reactions, raw gaps below the size filter, or gaps evicted from the registry. It never grants a trade, removes the key-sweep rule, or overrides manual bias. Keep your existing Fixed/Auto gap pairing on TF switches; diagnostic mode needs no TF tuning. Turn it Off after study.

**3.55 view for any pair/TF:** `Display → Chart view = Current (3.54)` preserves existing drawing density (the 3.55 wording/count corrections still apply). Choose `Clean` once if you prefer one nearest level and gap per side, at most one price-containing HTF gap (when its display option is on), and the enabled preview/confirmed plans, status, and compact D/T/E; it hides only auxiliary drawings. It does **not** alter the Fixed/Auto gap ladder, SMT sibling, TTFM filter, alerts or sizing and requires no adjustment when switching 1m/3m/5m/15m. On NQ, MNQ, ES, MES and XAUUSD, sizing uses `syminfo.pointvalue`; a displayed **SIZE 0** means no unit was calculated: check the risk budget and chart feed's point value—do not treat the drawn tag as a tradable order. Off-feed SMT remains unverified, not a positive signal.

**3.57 visual adaptation for every pair/TF:** TTrades → `HTF candle spacing = Auto (compact)` and Display → `Checklist panel position = Auto` are the **new display defaults**. HTF candle *drawings* start +24 chart bars on 1m, +18 on 2m–5m, +12 above 5m; their body/gap are 5/3 bars through 5m and 3/2 above 5m. On 1m–5m the checklist is middle right; above 5m it stays bottom right. No symbol-specific point conversion or manual adjustment on TF switches. Use `Manual (3.56)` for the 3.56 candle positions (start 50, width 5, gap 3, unless you customized them), and `Bottom Right` for the old panel position. Clean still hides the HTF candle strip but retains the compact checklist. This does not alter HTF pairing, gap delivery, entry eligibility, stops, grade, size or alert content. Pine cannot control TradingView's horizontal zoom, right margin or the browser window width.

**HTF gap lifecycle (3.51 default change):** `HTF FVG invalidation = Hybrid (HTF close)` follows each strictly higher slot TF automatically: 1H gaps await a confirmed 1H close, 15m gaps a 15m close, and so on. A chart-TF close beyond the far edge immediately marks the zone **BREACHED** (grey dashed, no delivery/target/sponsorship/edging/map credit), rather than deleting it; a confirmed source-TF close beyond deletes it, or a confirmed reclaim reactivates it for *future* setups. A manual Fixed slot at/below the chart TF and standalone sponsored 5m gaps still invalidate on chart close. `Also the gaps price is trading inside` defaults **On** (display only), making near-price gaps visible without manual TF-specific retuning. To restore **3.50**, set `HTF FVG invalidation = Chart close (3.50)` and `Also the gaps price is trading inside = Off`. Prefer matching broker/symbol/replay time when comparing, because a box is not proof of delivery.

**HTF CISD context (new 3.50, off by default):** set `Enable confirmed HTF CISD context = On` once; `HTF CISD timeframes = Auto` then picks 2m/3m on 1m, 5m/15m on 3m, 15m/30m on 5m, 1H/4H on 15m, 4H/1D on 1H. The chart and lower TFs are skipped. The 60-minute freshness window starts at the confirmed HTF candle's actual close (also across market gaps); it is wall-clock minutes, **not 60 chart bars**. `Draw confirmed HTF CISD lines` can be switched off independently without disabling the tooltip read. The 4-line cap is global. No change to entry eligibility, grade or alerts; on XAUUSD this is the same chart symbol's HTF candle-leg context, unrelated to the SMT sibling. If you choose Manual, use two distinct TFs above your entry chart.

**3.56 B-alert choice for every symbol/TF:** `Alerts → Alert rulebook-blocked B (study) = Off` by default. At `Show setups from grade = B` with `Rulebook blocks set the grade to B = On`, a reversal or Sweep + CISD outside NY AM still draws B/✖ but does not send a *confirmed* alert. Turn the study override On only if you need a clearly marked `STUDY BLOCKED` confirmed alert. If the B floor is not selected, the blocked tag remains hidden as before. All other B confirmations continue under the previous alert master, category, window and news rules. No per-timeframe tuning or change to entry, grade, sizing or SMT is implied. Forward alerts, not replay labels, are needed to verify delivery; recreate the TradingView alert after changing its input snapshot.

**Session defaults:** Asia 20:00–00:00; London 02:00–05:00; Premarket 08:00–09:30; NY AM 09:30–11:00. Trading windows: Asia/London/NY AM. Judas: 09:30–09:45. Macro windows: 09:50–10:10 and 10:50–11:10. Automatic NFP blackout approximates first Friday 08:30 NY (check actual release date); type other red-folder dates in `Other releases` each week. The optional alert windows narrow, never widen, the original trading/news window gate.

**Default differences from uploaded 3.47:** 3.57 now defaults to Auto (compact) HTF candle drawings and an Auto checklist position; both are visual-only with 3.56 manual/fixed opt-outs. The 3.55 Chart view still defaults to Current (3.54), so Clean must be chosen explicitly; the 3.56 rulebook-blocked B study alert override defaults Off (new confirmed-alert suppression when the B display floor is chosen); the diagnostic defaults Off; 3.51 uses Hybrid gap invalidation and shows gaps containing price; a reclaimed HTF gap can qualify only *after its own confirmed close*. Setup grade/draw/targets therefore may differ from 3.47 or 3.50; compare in replay before relying on this default. Earlier 3.48–3.50 additions kept their original defaults. New dedup defaults **off**, sibling mode **Auto**, alert master/categories **on**, separate alert windows **off**, `HTF gap timeframe mode` defaults **Fixed**, `Drawings after stop` defaults **Keep**, and `Stop touch means` defaults **Wick** (inactive while Keep), and `Enable confirmed HTF CISD context` defaults **Off** (its Auto TF map and drawing defaults are inactive until on). Manual sibling defaults to ES but is inactive in Auto. An earlier non-optional safety fix ensures that a configured but unavailable SMT sibling does not count as valid correlation data; 3.56 also intentionally suppresses rulebook-blocked B confirmed alerts by default. For a control run, leave every new toggle at its default and compare the same symbol, same broker, same timeframe and date in TradingView; only turn one new control on at a time.

**Settings title cleanup (CW10026):** `Sweep + CISD within (min)` is now its own Setup row rather than an inline second title beside `Sweep + CISD setups (6.6)`. Default 30 and the NY-AM-only rule are unchanged; no timeframe switching adjustment is needed.
